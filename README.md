# 刘李金 · Li-Jin Liu

个人主页，收录前端与 AI 应用项目，以及计算机视觉论文和预印本。

Personal website featuring frontend and AI application projects, computer vision publications, and a preprint.

- [中文主页](https://lijin6.github.io/)
- [English homepage](https://lijin6.github.io/?lang=en)

## 页面 / Website

首页提供中英文切换，英文可通过 `?lang=en` 直接访问。主题默认跟随系统设置，也可手动选择浅色或深色，选择保存在当前浏览器。

The homepage supports Chinese and English. Open the English version directly with `?lang=en`. The theme follows the system preference by default, and a manual light or dark selection is saved in the browser.

## 维护 / Development

- `index.html` — 首页内容、样式和切换逻辑 / Homepage content, styling, and controls
- `about.html` — 将旧的 About 地址转到首页简介 / Redirects the old About URL to the homepage biography
- `_config.yml` — GitHub Pages / Jekyll 配置 / Site configuration

安装 Ruby 和 Bundler 后，在仓库根目录运行以下命令。提交到 `main` 后，由 GitHub Pages 构建站点。

With Ruby and Bundler installed, run these commands from the repository root. GitHub Pages builds the site from the `main` branch.

~~~sh
bundle install
bundle exec jekyll serve
~~~

打开 / Open [localhost:4000](http://localhost:4000/).
