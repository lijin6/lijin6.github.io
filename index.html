关于我About

我用 React 和 TypeScript 开发 Web 界面，也用 Python 和 FastAPI 将视觉模型接入应用。我的科研项目集中在高分辨率图像检测与遥感视觉，主要负责实验、代码实现和论文撰写。I build web interfaces with React and TypeScript and integrate computer vision models into applications with Python and FastAPI. My research projects focus on high-resolution detection and remote sensing. I primarily run experiments, implement code, and write manuscripts.
